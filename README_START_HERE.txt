Bank Marketing Streamlit application starter files.
1. Keep app.py, requirements.txt, test_data.csv and model/ together in the repository root.
2. Use Python 3.11 or 3.12 for scikit-learn 1.6.1 compatibility.
3. Install: python -m pip install -r requirements.txt
4. Run: streamlit run app.py
5. Upload test_data.csv in the sidebar and choose a model.
6. Write your own README.md with problem statement, dataset description, six-metric comparison, individual model observations, winner, and repository link.
7. Add your own notebook/source and BITS Virtual Lab screenshot to the final submission PDF.
